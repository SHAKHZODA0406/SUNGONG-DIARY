# 순공 다이어리

TOPIK II 6급을 위한 공부 타이머 앱 (Android).

- 듣기 · 읽기 · 쓰기 영역별 카운트다운 타이머, 오늘 · 총 누적 순공 시간
- 매일 아침 D-day 알림 + 하루 7번 응원 메시지 (인터넷 없이 동작)
- 공부 잔디, 주간 기록, 성적 관리

## 설치

1. 휴대폰/태블릿에서 이 저장소의 **Releases** 페이지를 엽니다.
2. 가장 최신 버전의 `SunGong-Diary.apk`를 내려받아 설치합니다.
   (처음 한 번은 "출처를 알 수 없는 앱 설치"를 허용해야 해요.)

## 빌드

`main` 브랜치에 push하면 GitHub Actions가 APK를 만들어 Releases에 올립니다.
